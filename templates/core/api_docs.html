API v1

OpenAPI Mis claves

URL base: {{ base }}. Todas las respuestas son JSON (UTF-8); los importes van como texto decimal (ej. "1180.00") y las fechas como AAAA-MM-DD.

Autenticación: cabecera Authorization: Bearer <clave>. La clave actúa con los módulos y permisos de su usuario; las de solo lectura solo admiten GET. Límite: 120 solicitudes por minuto.

Listas: paginadas con page y page_size (máx. 1000); responden {"count", "page", "pages", "results"}. Con formato=csv devuelven todo el resultado en un archivo CSV (separador ;, abre directo en Excel o se carga a Power BI).

Fechas: desde y hasta como AAAA-MM-DD (fecha del documento o del movimiento); en los reportes contables, periodos AAAA-MM (por defecto, de enero al mes actual) y libro=NIIF o TRIBUTARIO. Los costos (kardex, stock valorizado, órdenes de producción) solo salen si el usuario de la clave puede ver costos.

Errores: {"error": "...", "campos": {...}} con 400 (parámetro inválido), 401 (clave), 403 (permiso), 404, 422 (validación) o 429 (límite).

POST {{ base }}ventas/
{
  "tipo_comprobante": "03",
  "tercero_numero_doc": "45678912",
  "forma_pago": "CONTADO",
  "items": [
    {"codigo": "P002", "cantidad": 2},
    {"descripcion": "Delivery", "cantidad": 1,
     "precio_unitario": "8.47", "afectacion": "GRAVADA"}
  ]
}

Mismas validaciones que la pantalla (serie del usuario, stock, crédito, periodo). Sin precio_unitario se usa el precio de venta del producto; también acepta descuento_pct, fecha_emision, moneda, serie y almacen. Si la facturación electrónica tiene envío automático, el comprobante se envía a SUNAT.
