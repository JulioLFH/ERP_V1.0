Configuración manual (fuera de Ceiba):

  • WhatsApp: el botón de la oportunidad abre el chat (click-to-chat) y deja la actividad; la conexión a la API oficial de WhatsApp de Meta (número de la empresa, plantillas aprobadas) requiere contratar la cuenta con Meta.
  • Formularios de anuncios de Facebook / Instagram: se conectan enviando sus datos al enlace del formulario (con una herramienta de integración o la API de Meta).
  • Recordatorios por correo: configure el correo saliente (Ajustes › Correo saliente) y programe la tarea diaria python manage.py recordatorios_crm.
  • Correo a oportunidad: complete el buzón comercial (IMAP) en esta pantalla y programe cada pocos minutos python manage.py leer_correo_crm: cada correo nuevo crea su oportunidad con origen «Correo».
